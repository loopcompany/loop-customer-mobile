# تابع تبدیل تاریخ شمسی به میلادی

## 📍 مکان
`helpers/Common.js` → `jalaliToGregorian()`

## 📝 توضیحات
تابعی برای تبدیل دقیق تاریخ شمسی (جلالی) به میلادی (گرگوریان) با استفاده از کتابخانه `jalaali-js`.

## 🔧 استفاده

### Import
```javascript
import { jalaliToGregorian } from '../helpers/Common';
```

### مثال‌های استفاده

```javascript
// مثال 1: تبدیل ساده
const gregorianDate = jalaliToGregorian('1402/08/17');
console.log(gregorianDate); // "2023-11-08"

// مثال 2: در فرم ثبت نام
const handleRegister = async () => {
  const birthDateGregorian = jalaliToGregorian(birthDate); // birthDate: "1370/01/15"
  
  formData.append('birthdate', birthDateGregorian); // "1991-04-04"
};

// مثال 3: بررسی خطا
const result = jalaliToGregorian('1402/13/01'); // ماه نامعتبر
console.log(result); // "" (رشته خالی)
```

## 📥 ورودی
- **نوع**: `string`
- **فرمت**: `YYYY/MM/DD` (مثال: `1402/08/17`)
- **توضیح**: تاریخ شمسی با جداکننده `/`

### محدودیت‌های ورودی:
- سال: عدد صحیح مثبت
- ماه: `1` تا `12`
- روز: `1` تا `31`

## 📤 خروجی
- **نوع**: `string`
- **فرمت**: `YYYY-MM-DD` (مثال: `2023-11-08`)
- **خطا**: رشته خالی `""` در صورت ورودی نامعتبر

## ✅ تست‌های موفق

| تاریخ شمسی | تاریخ میلادی | توضیح |
|------------|--------------|-------|
| `1402/08/17` | `2023-11-08` | ۱۷ آبان ۱۴۰۲ |
| `1370/01/15` | `1991-04-04` | ۱۵ فروردین ۱۳۷۰ |
| `1400/12/29` | `2022-03-20` | آخرین روز سال |
| `1401/01/01` | `2022-03-21` | اول سال |
| `1403/01/01` | `2024-03-20` | سال کبیسه |
| `1380/06/31` | `2001-09-22` | آخرین روز شهریور |
| `1399/11/30` | `2021-02-18` | سال کبیسه شمسی |

## ❌ مدیریت خطاها

| ورودی | خروجی | دلیل |
|-------|-------|------|
| `""` | `""` | رشته خالی |
| `null` | `""` | مقدار null |
| `undefined` | `""` | مقدار undefined |
| `1402/13/01` | `""` | ماه نامعتبر (> 12) |
| `1402/01/32` | `""` | روز نامعتبر (> 31) |
| `1402-08-17` | `""` | فرمت اشتباه (با `-`) |
| `1402/08` | `""` | ناقص (بدون روز) |
| `abc/def/ghi` | `""` | حروف به جای عدد |

## 🎯 موارد استفاده در پروژه

### 1. ثبت نام سازمانی (`org/logreg/Register.js`)
```javascript
const handleRegister = async () => {
  // تبدیل تاریخ تولد از شمسی به میلادی قبل از ارسال
  const gregorianDate = jalaliToGregorian(birthDate);
  
  formData.append('manager_birthdate', gregorianDate);
  
  // ارسال به API
  await axios.post(`${uri}/organization/register`, formData);
};
```

### 2. نمایش تاریخ در رابط کاربری
```javascript
// کاربر تاریخ شمسی انتخاب می‌کند
const [birthDate, setBirthDate] = useState('1370/01/15');

// به API میلادی ارسال می‌شود

```

## 📞 سوالات متداول

### Q: چرا از `/` به جای `-` استفاده می‌کنیم؟
**A:** فرمت `/` در DatePicker شمسی استاندارد است. تابع فقط این فرمت را می‌پذیرد.

### Q: آیا از سال‌های کبیسه پشتیبانی می‌کند؟
**A:** بله، کتابخانه `jalaali-js` به طور کامل سال‌های کبیسه را پشتیبانی می‌کند.

### Q: اگر ورودی نامعتبر باشد چه اتفاقی می‌افتد؟
**A:** تابع رشته خالی `""` برمی‌گرداند و خطایی throw نمی‌کند.

### Q: آیا می‌توانم فرمت خروجی را تغییر دهم؟
**A:** بله، کد را در `helpers/Common.js` تغییر دهید. فرمت فعلی `YYYY-MM-DD` با استانداردهای API سازگار است.
