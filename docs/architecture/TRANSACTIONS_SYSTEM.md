# Transactions System Implementation - سیستم تراکنش‌ها

## 📝 نمای کلی

سیستم تراکنش‌ها امکان مشاهده تاریخچه تراکنش‌های کیف پول کاربر را فراهم می‌کند. تراکنش‌ها شامل شارژ کیف پول، پرداخت سفارش و بازگشت وجه می‌باشند.

## 📁 فایل‌های ایجاد/ویرایش شده

### فایل‌های ویرایش شده:
1. **`screens/TransactionsScreen.js`**
   - بازنویسی کامل با اتصال به API جدید
   - پشتیبانی از refresh
   - نمایش لودینگ
   - رنگ‌بندی بر اساس وضعیت تراکنش
   - نمایش pagination
   - تبدیل قیمت از تومان به ریال (× 10)

### فایل‌های جدید:
1. **`services/WalletApi.js`**
   - سرویس API برای مدیریت کیف پول
   - توابع: getTransactions, chargeWallet, payOrderFromWallet, getWalletBalance

## 🎯 ویژگی‌های پیاده‌سازی شده

### API Integration:
✅ **GET /api/wallet/transactions**
- دریافت لیست تراکنش‌ها
- پشتیبانی از فیلترهای تاریخی (from_date, to_date)
- Pagination (per_page, page)

### رنگ‌بندی بر اساس وضعیت:
```javascript
status = 100  → سبز (موفق) - themeColor7
status = -1   → قرمز (ناموفق) - themeColor6
status = 0    → آبی (در انتظار) - themeColor0
```

### تبدیل قیمت:
```javascript
// قیمت از API به تومان است
// نمایش به ریال: × 10
formatPrice(item.price * 10) + ' ریال'
```

### انواع تراکنش:
```javascript
type = 1 → شارژ کیف پول
type = 2 → پرداخت سفارش
type = 3 → بازگشت وجه
```

## 🔧 استفاده

### کد نمونه:
```javascript
import { getTransactions } from '../services/WalletApi';

// دریافت تراکنش‌ها
const data = await getTransactions(token);

// با فیلتر تاریخ
const data = await getTransactions(token, {
  from_date: '2025-01-01',
  to_date: '2025-01-31',
  per_page: 20,
  page: 1
});
```

## 📱 Screen Features

### 1. Pull to Refresh:
- کشیدن به پایین برای بروزرسانی
- نمایش Spinner در حین refresh

### 2. نمایش اطلاعات تراکنش:
- تاریخ و زمان (formatDateTime)
- مبلغ به ریال (× 10)
- نوع تراکنش (شارژ/پرداخت/بازگشت)
- وضعیت (موفق/ناموفق/در انتظار)
- شماره پیگیری
- توضیحات

### 3. رنگ‌بندی هوشمند:
- کارت‌های تراکنش با رنگ وضعیت
- Badge وضعیت شفاف روی کارت

### 4. Pagination Info:
- نمایش شماره صفحه فعلی
- تعداد کل صفحات
- تعداد کل تراکنش‌ها

## ⚠️ نکات مهم

1. **قیمت‌ها به تومان است**: از API قیمت به تومان می‌آید، برای نمایش در 10 ضرب می‌شود
2. **رنگ از وضعیت**: رنگ کارت مستقیماً از `status` تراکنش گرفته می‌شود
3. **Pagination**: در نسخه فعلی فقط اطلاعات نمایش داده می‌شود (صفحه‌بندی دستی پیاده نشده)
4. **Refresh**: با کشیدن به پایین لیست بروزرسانی می‌شود
5. **Loading State**: در اولین بارگذاری Spinner نمایش داده می‌شود
