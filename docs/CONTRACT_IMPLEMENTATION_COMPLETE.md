## 🔄 تغییرات کلیدی

### 1️⃣ تابع `loadContractData()` - دریافت اطلاعات قرارداد

**قبل:** Mock data  
**بعد:** اتصال به 2 API واقعی

```javascript
// API 1: دریافت آخرین قرارداد عمومی
GET /api/contracts/latest

// API 2: دریافت لیست قراردادهای سازمان
GET /api/organization/contracts
```

**ویژگی‌های جدید:**
- ✅ دریافت قرارداد عمومی از ادمین
- ✅ دریافت آخرین قرارداد آپلود شده سازمان
- ✅ نمایش وضعیت قرارداد (`pending`, `approved`, `rejected`)
- ✅ نمایش دلیل رد شدن
- ✅ مدیریت خطاهای 403, 404

---

### 2️⃣ تابع `handlePickDocument()` - انتخاب فایل

**تغییرات:**
- ✅ بررسی امکان آپلود (اگر approved باشد، امکان آپلود نیست)
- ✅ محدودیت فرمت: فقط PDF (مطابق API docs)
- ✅ حداکثر حجم: 500 MB (مطابق API docs)
- ✅ پیام‌های خطای مناسب

```javascript
// بررسی وضعیت قرارداد فعلی
if (uploadedContract && uploadedContract.status === 'approved') {
  Alert.alert('توجه', 'شما یک قرارداد تایید شده دارید');
  return;
}

// فقط PDF
type: ['application/pdf']

// حداکثر 500MB
if (file.size > 500 * 1024 * 1024) {
  Alert.alert('خطا', 'حجم فایل نباید بیشتر از 500 مگابایت باشد');
}
```

---

### 3️⃣ تابع `handleUploadContract()` - آپلود قرارداد

**تغییرات کلیدی:**

**قبل:**
```javascript
formData.append('contract', {...}); // اشتباه
// Mock API call
```

**بعد:**
```javascript
formData.append('contract_file', {...}); // صحیح - مطابق API docs

// API واقعی
POST /api/organization/contracts/upload
```

**مدیریت خطا:**
```javascript
- 400: قرارداد تایید شده وجود دارد
- 422: خطای validation (نمایش تمام خطاها)
- 404: اطلاعات سازمان یافت نشد
```

## 📊 جریان کار (User Flow)

### حالت 1: سازمان جدید (بدون قرارداد)

```
1. ورود به صفحه
2. دانلود قرارداد عمومی ادمین
3. امضا و اسکن قرارداد
4. انتخاب فایل PDF
5. آپلود قرارداد
6. وضعیت: "در انتظار بررسی" (نارنجی)
```

### حالت 2: قرارداد رد شده

```
1. مشاهده دلیل رد در باکس قرمز
2. مطالعه دلیل رد
3. اصلاح قرارداد
4. آپلود مجدد
5. وضعیت: "در انتظار بررسی" (نارنجی)
```

### حالت 3: قرارداد تایید شده

```
1. مشاهده وضعیت "تایید شده ✓" (سبز)
2. تاریخ بررسی نمایش داده می‌شود
3. دکمه "انتخاب فایل" غیرفعال می‌شود
4. پیام: "شما یک قرارداد تایید شده دارید"
```

## 🔧 نکات فنی

### Field Mapping (API → Frontend):

| API Field | Frontend State | توضیحات |
|-----------|----------------|---------|
| `pdf_url` | `file_url` | URL فایل PDF |
| `title` | `title` + `file_name` | عنوان قرارداد |
| `created_at` | `uploaded_at` | تبدیل به تاریخ شمسی |
| `contract_url` | `file_url` | URL قرارداد آپلود شده |
| `status` | `status` | pending/approved/rejected |
| `status_label` | `status_label` | برچسب فارسی |
| `rejection_reason` | `rejection_reason` | دلیل رد |
| `reviewed_at` | `reviewed_at` | تاریخ بررسی |
| `can_edit` | `can_edit` | امکان ویرایش |

### تبدیل تاریخ:

```javascript
// ISO 8601 → تاریخ شمسی
new Date(contract.created_at).toLocaleDateString('fa-IR')
// Output: "1403/8/17"
```
